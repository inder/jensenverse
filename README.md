# JENSENVERSE

A browsable Jensen Huang meme library: https://inder.github.io/jensen-huang-memes/

## Collection

32 curated entries across X, YouTube and Reddit, plus three grouped alternate uploads. Categories cover Hollywood, Bollywood, Korean, Chinese-language captions, broader Asian references, music, political satire, internet classics, comedy and tech/finance. Sports remains an explicitly empty category until a suitable meme is verified. Categories reflect the meme format or source language, not a person’s ethnicity.

The collection includes AI parodies, captioned clips, performed comedy, film edits, a meme review and one image reply. Satire labels describe content type; allegations made by meme captions are not presented as facts. Alternate uploads are not counted as unique entries. Poster/uploader credit does not establish original authorship.

## Features

Search, category/platform/format filters, curated/newest order, saved items stored only in the visitor’s browser, per-item share links, surprise picks, and detail views with optional official X/YouTube embeds. Social players load only on request. Thumbnails are served from their source platforms; no video files are copied or rehosted.

## Verification

Metadata and links checked November 12, 2026. `data.json` contains per-entry source and verification notes; `link-verification.json` records the audit. X original pages and official oEmbed records were checked. YouTube metadata reported playable, embeddable videos at check time. Reddit entries were checked against public posts, media previews and contextual evidence. Full playback was not independently watched. Availability, thumbnails and regional playback can change.

## Hosting and editing

GitHub Pages serves the root of `main`. No build step or server is required. Edit `data.json` for collection updates; edit `index.html`, `styles.css` and `app.js` for presentation. Preview with a static HTTP server. No analytics or account system is installed. Saved items do not sync across devices.

Use repository issues to suggest a clip or report a broken link. Suggestions are not automatically published. This is an independent fan archive, unaffiliated with NVIDIA or the people depicted.
